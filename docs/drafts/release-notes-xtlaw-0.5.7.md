## 改进

- **草稿恢复**发生冲突时，可对照查看当前输入与已保存的草稿，选择保留其中一份，或清空后重新输入。
- **超长任务历史**分批加载。打开任务时先显示可用的对话内容，其余运行记录随后加载，减少历史过大造成的连接中断。
- **流式对话**期间打开文本文件时，编辑器初始化会延后，减少对正在更新的对话界面的影响。
- **服务模型列表**按可见范围渲染，模型较多时滚动更流畅。自定义模型服务可选择免认证，连接无需 API 密钥的服务。

## 修复

- 修复编辑并重发消息后，继续发送时可能遇到的草稿冲突。
- 修复 Windows 粘贴大图时剪贴板返回空图片数据的问题。
- 修复前台打开内置浏览器时，面板显示和页面导航有时被提前取消的问题。
- 修复首次新建任务的草稿未继承引导流程中所选权限的问题。
- 修复图片查看器按钮和头像的对比度，并调整归档清理的进度提示和撤销提示时长。

## 升级说明

现有数据库会自动补齐自定义模型服务的认证配置字段，数据库版本号保持原值。

Office 插件通过插件市场单独更新。相关版本改善了窄面板中的工具栏菜单，并修复 PDF 分块读取问题。
