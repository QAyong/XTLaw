## 合并前修复（2026-10-14）

在开发预览中发现以下问题，在同步分支上修复，各自单独提交后随本轮一起合并：

- **伙伴页右侧空白**：伙伴页照搬上游的 `#workspace` 插槽，本地 `WorkbenchLayout` 的主区域是默认插槽，详情组件因此没有渲染。`DesktopBuddiesView.vue` 改用默认插槽，与本地设置页一致。

- **凭据错误可诊断**：凭据库失败时标记出错阶段（列目录、读文件、解密、解析、校验、加密、写入、删除），诊断日志记录 `credential.<阶段>.failed`，只含请求方法、异常类型和系统错误码，不记异常消息，避免泄露解密内容。返回给 runtime 的错误码不变。起因是开发预览曾报 `CREDENTIAL_STORE_FAILURE` 但无法复现；用凭据副本在 Electron 44.4.5 和 44.7.0 下验证，`sessionData` 中的 `Local State` 均能解密，凭据和密钥没有损坏。
- **聊天欢迎区与上游一致**：去掉 XTLaw 文字标，问候语移到标题上方，字号、字重、间距同上游。Feature-023 已同步更新。
