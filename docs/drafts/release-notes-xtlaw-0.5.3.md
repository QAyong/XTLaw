## 升级前请注意

- 如果你安装的 0.5.2 点“检查更新”一直提示“暂时无法检查更新”，是 GitHub 偶发返回的一次重定向被缓存了，0.5.2 里没法自己恢复，请直接从发布页下载本版本安装。装上之后不会再出现。想保留 0.5.2 继续用的话：完全退出 XTLaw（托盘里退出，关窗口不够），把 `%USERPROFILE%\.xtlaw\device\chromium\Cache` 改名备份，再启动；插件包和安装包的下载缓存会重新下载。
- 本版本没有数据库迁移。
- 对话列表的渲染方式有较大改动（见“改进”），长对话里的滚动、重新生成、分屏和折叠都用到了新逻辑。使用中发现位置跳动、正文空白或折叠状态不对，请反馈。

## 新增

- **逐题作答**：智能体一次提出多个问题时，可以一题一题回答。
- **添加服务时可以全选或清空模型**：添加服务向导的模型步骤里，对当前列表的模型一键全部启用或全部关闭。
- **任务分区折叠时显示运行状态**：侧栏里折叠起来的任务分区，里面有任务在运行或等待审批时，分区标题上会显示对应的图标。

## 改进

- **长对话更流畅**：对话列表改为只绘制屏幕附近的消息，长对话里消息不再全部同时绘制；拖动分屏分隔条时每一帧只更新一次，输入框下方工具栏的收缩也不再每次都重新测量。滚出屏幕再滚回来时，过程的折叠状态、展开的内容和选中的文字会保留。
- **重新生成**：在长对话中间重新生成回复时，页面不再因为旧回复被暂时移除而跳动，已经加载的更早历史也会保留。
- **子任务权限**：子任务以“只读文件”角色运行时，网络请求和审批沿用基础模式的设置，不再被一并降成本地只读；写入、删除和非沙箱执行仍然被拒绝。
- **问答面板**：正文和面板的布局更清晰。

## 修复

- 修复“检查更新”被缓存的重定向永久卡住：每次都向 GitHub 重新验证，并跟随同域的 301。
- 修复系统语音的初始化和第一次朗读。
- 修复编辑消息、重新生成之后对话的加载状态。
- 修复任务运行时侧栏转圈图标上下起伏。
