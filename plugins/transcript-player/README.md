# ArtPlayer

在文件页签中使用 ArtPlayer 5.4.0 播放音视频。左侧播放器，右侧「文字记录｜智能纪要」，默认约 60:40，可拖动分隔条或用方向键调整。窄页签自动改为上下布局。

- 底栏左侧原有的加载字幕操作保持不变，支持 SRT、VTT 或 ASS；右侧 CC 仍只开关画面字幕。同一个视频下次打开会沿用上次的字幕。
- 文字记录按阅读段落展示字幕，不虚构说话人。点击句子或时间戳跳转播放，播放时高亮当前句；手动滚动后停止跟随，点击「回到当前播放位置」恢复。搜索支持命中计数、上一处和下一处，Enter / Shift+Enter 切换命中。
- 「智能纪要」暂时仅为空占位，不调用 Agent、不附带 Skill，也不自动生成内容。
- 播放栏的「全屏播放」仅在当前文件页签内展开播放器、收起右侧面板；再次点击或按 Esc 恢复，保留分栏比例、右侧页签和文字内容。不是系统级全屏，不关闭画面 CC 字幕，不影响应用聊天栏。
- 不改 ArtPlayer 源码，不另做播放控制条。系统全屏、网页全屏和截图仍未开启。

加载字幕需要本地文件权限。安装时不会预选为默认播放器。在「设置 → 打开方式」里把对应后缀改为 ArtPlayer，关掉已打开的文件后再打开。

```sh
pnpm install
pnpm type-check
pnpm test
pnpm build
```

`dist/` 是可加载的 compiled 目录，ArtPlayer 已打进 `view.js`。单元测试覆盖字幕分段、搜索、高亮定位和时间格式；不代替 Windows 宿主内的实机交互验收。
