## 升级前请注意

- 本版本新增 2 个数据库迁移（多智能体的工作交接与续做、智能体身份），首次启动新版本时会自动升级本地数据库，升级后不能回退到旧版本。建议升级前先在设置里创建一份备份。
- 插件新增了几项受控能力（直接编辑本地文件、受控剪贴板、受控私有文件、WebAssembly 与 Worker、随插件分发技能）。已安装的插件不会自动获得这些权限，需要插件作者发布新版本后，由你在安装审核里确认。

## 新增

- **插件市场扩展为“能力市场”**：除了插件，还能在市场里安装和卸载 MCP 连接、技能和子智能体；支持按形态和来源筛选，并新增“新增”菜单。已安装页会展示市场包带来的 MCP、技能与子智能体，插件卡片随内容增高，不再固定 200px。市场目录已指向改名后的 `xtlaw-market` 仓库。
- **能力包**：市场新增能力包与货架；子智能体可以整选一个连接器的全部工具，不必逐个勾选。
- **对话分支**：对话模式支持分支，分支不再显示序号前缀和提示。
- **多智能体**：改进工作交接与续做，修复智能体身份与完成反馈。
- **插件能力**：
  - 插件可以直接编辑本地文件、创建受控的私有文件，并使用受控剪贴板。
  - 插件可以携带技能一起分发；插件安装审核里的权限按资源分组展示。
  - 支持 WebAssembly 与 Worker，并向声明了该能力的插件的宿主页面开放；移除了 WebAssembly 的安装限制和风险标签。
  - 支持插件引用与来源定位、文件打开与启动器，以及原生菜单引用；`accepts.extensions` 会登记为隐式文件处理器。
- **账号菜单重做**：新增个人信息头部、主题切换和检查更新。
- **自定义通知提示音**，以及新增“输出卡片打开位置”设置。
- **工作区**：资源面板位置按任务记忆；上下文标签页支持固定和批量关闭；轮次产出标题可折叠；Office 输出卡片在文件管理器中打开时会显示文件树。
- **法律检索技能重组**：围绕任务模板和更简洁的流程重新整理。
- **Pi 升级到 1.4.0**，默认启用 Codemode。
- 模型选择控件里的服务商标志跟随主题；浏览器工具栏高度更紧凑。

## 改进

- 过长的用户消息默认折叠为五行。
- 设置里的技能页加入来源缓存与批量读取，打开更快。
- 消息文本里的文件打开方式与右键菜单统一；产物卡片的操作与上游对齐。
- 域名权限表更易读。

## 修复

- 修复 shell 执行模式与声明不一致的问题。
- 修复切换任务时阅读位置没有恢复的问题。
- 修复浏览器加载反馈缺失和出错后无法重试的问题。
- 修复伙伴会话续接和执行过程显示的问题。
- 修复插件工具输出里换行被转义的问题。
