## 升级前请注意

- 本版本没有新增数据库迁移。
- XTLaw播放器是独立插件，不随应用安装包附带。下面的播放器功能需另行安装或更新该插件；应用内置的默认播放器保持不变。

## 新增

- **独立的聊天阅读宽度**：聊天正文的阅读宽度可单独设置，不必随面板宽度一起变化。
- **点击头像点名伙伴**：点击伙伴头像即可在输入框中点名对应伙伴。
- **侧栏等待回答状态**：任务等待你回答问题时，侧栏会与正在执行的任务显示不同状态。
- **Agnes 图像协议**：新增对 Agnes 图像协议的兼容。

## 改进

- **提问选项边框**：去掉选项边缘的双层不规则描边，改用与补充说明输入框一致的单层边框，保留选中时的蓝色填充。
- **引用来源更清楚**：引用消息显示原角色名称。
- **长对话阅读**：改进虚拟滚动、阅读位置恢复和高度估算，减少切换对话、滚动历史及调整分屏时的跳动。
- **侧栏运行指示**：修复运行中圆环的显示，并统一为更紧凑的尺寸。
- **模型运行引擎**：Pi 升级至 1.5.0。

## 修复

- 修复发送首条消息后，已调整的面板位置被换回。
- 修复子任务画布的焦点定位时序。
- 修复 Markdown 中任务工作区图片的路径解析。
- 修复隐藏视口被当作滚动位置为零，影响原有阅读位置。
- 修复部分队列内容重复展示。
- 修复浏览器页面加载较慢时被误判为无响应。
- 插件宿主改用独立心跳判断响应状态，不再仅凭请求耗时认定插件故障。
- 清理部分界面中遗留的旧品牌文案。

## 独立插件：XTLaw播放器

以下功能不包含在应用安装包中：

- 音视频可在独立页签中打开，并配有紧凑播放界面。
- 支持手动加载和记住已选字幕，以文字稿形式阅读，并跟随播放位置高亮。
- 支持段落引用、文字选区引用和来源定位；选区菜单统一通过右键打开。
- 支持文字稿面板与页签内全屏阅读，提供返回当前播放位置的悬浮按钮。
- 改进段落间距、菜单一致性和深色主题高亮配色。
