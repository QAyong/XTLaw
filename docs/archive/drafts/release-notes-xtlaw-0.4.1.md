## 升级前请注意

- 本版本把本地数据库版本从 36 升到 37（不改表结构），首次启动新版本时会自动升级。升级后不能回退到旧版本，建议升级前先在设置里创建一份备份。
- 新任务的“完全访问”语义已落实：选择完全访问后，工具操作免审批，可访问本机文件、凭据和网络。确认对话框和设置页都加了说明，请只对可信任务开启。

## 新增

- **最新回复也能分叉**：以前只有后面还有消息的旧回复才有“追问/分叉”按钮，现在最新一条已完成的回复也可以直接分叉，对话画布里同样生效。
- **工作中发送消息的方式可配置**：在设置的“执行行为”里选择，运行中发送的新消息是“补充当前工作”（在执行边界加入）还是“排队”（等当前工作结束后处理）。输入框里可以看到每条消息的投递去向（补充当前工作 / 完成后处理 / 回答当前问题），未投递的消息可以撤回，排队消息仍可单独立即发送。

## 改进

- 完善消息投递与对话时间线，投递目标已结束或无法接收时会保留输入并给出提示。
- 网页请求超过并发上限时，在主进程侧排队等待，不再直接拒绝；搜狗微信搜索及其会话 Cookie 处理保持不变。
- 更新包下载优先走 GitHub 镜像，更新提示弹窗头部改用应用图标。
