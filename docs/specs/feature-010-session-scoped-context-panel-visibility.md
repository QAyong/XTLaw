# Spec-010：工作区视窗状态跟随会话

**日期：** 2026-09-30
**状态：** 原任务/独立模式已验收；2026-10-09 空间模式集成及定向自动验证通过，新增桌面交互待手动验收

## 0. 空间联动扩展（2026-10-09）

保留下面记录的任务模式和独立浏览规则，新增 `space` 模式，不把任务级资源所有权改成空间级所有权：

- `task`：标签、选择和面板开合按任务/草稿隔离，保留原有按会话布局记忆。
- `space`：同空间共享标签、选中项和开合状态；无空间任务/草稿仍独立。任务空间成员关系变化时重新计算可见标签，删除任务仅移除它拥有的资源。
- `independent`：全局资源选择和全局面板开合保持原有语义。

开合状态与选中标签使用 `ContextPanelSelectionScope`（含 `space:<id>`）保存和恢复，各模式的选择/开合记忆分离。空间模式不会把原任务模式的左右换位或最大化偏好迁移成新的空间所有权；拖放和页面导航造成的临时可见性由 `useContextPanePresentation.ts` 管理，不覆盖用户保存的偏好。

新增 `apps/buddy/src/app/workbench/useTaskResourceSpaces.ts` 维护任务/草稿到空间的映射，`useSpaceContextPanel.spec.ts` 覆盖共享、成员变更、草稿提交、模式切换和空间开合恢复。当前 11 项通过；完整验证及边界见 [集成记录](../upstream-remaining-integration.md)。

## 1. 背景

桌面端资源面板的展开/收起状态、资源面板与聊天区的位置，以及聊天区是否隐藏，都影响当前会话的工作区布局。任务联动模式下，这些状态应按会话分别保存；新会话采用默认布局，切回旧会话则恢复该会话上次的布局。

独立浏览模式不跟随会话选择资源，其位置和聊天区显隐继续作为全局临时状态。页面导航不应清除当前布局；关闭资源面板时，隐藏聊天区状态清除，避免资源面板关闭后工作区仍被隐藏。

## 2. 需求边界

**包含：**
- 任务联动模式下，资源面板开合、左右位置和聊天区显隐按会话分别保存。
- 新会话或没有状态记录的会话使用默认布局：资源面板收起、聊天区显示、资源面板位于右侧。
- 切回已有会话时恢复其上次的面板和视窗状态；离开页面再返回不重置状态。
- 独立浏览模式下，资源面板开合、位置和聊天区显隐保持全局临时状态，不因会话或页面切换而重置。
- 关闭资源面板时清除聊天区隐藏状态；再次打开资源面板时聊天区可见。
- 将会话布局状态与资源标签、选中标签一起写入现有工作台辅助状态快照。

**不包含：**
- 不改变资源标签按会话隔离的规则。
- 不改变独立浏览模式的全局资源选择或全局面板开合语义。
- 不改变任务侧栏布局。
- 应用重启后不恢复任务联动模式的位置交换或聊天区隐藏状态，仍使用默认布局。
- 不新增服务端配置或跨设备同步。

## 3. 状态规则

| 场景 | 面板状态 |
|---|---|
| 新建会话，且没有历史状态 | 收起 |
| 切换到已记录的会话 | 恢复该会话上次状态 |
| 当前会话手动展开/收起、交换位置或隐藏聊天区 | 更新当前会话布局状态 |
| 新建会话或切换到无记录会话 | 资源面板收起、聊天区显示、资源面板位于右侧 |
| 切换到另一个已有会话 | 恢复目标会话上次的资源面板和视窗布局 |
| 独立浏览模式中切换任务会话或页面 | 保持独立浏览的全局布局状态 |
| 从独立浏览切回任务联动 | 恢复当前会话的布局；无记录则使用默认布局 |
| 关闭资源面板 | 清除聊天区隐藏状态 |

## 4. 验收标准

- [x] 任务联动模式中，会话分别记忆资源面板开合、左右位置和聊天区显隐；切换回来完整恢复。
- [x] 新建会话以及从未设置状态的会话使用默认布局，不继承前一会话状态。
- [x] 独立浏览模式切换任务或页面时保持全局布局状态。
- [x] 从独立浏览切回任务联动时恢复当前会话布局。
- [x] 工作台辅助状态快照可恢复会话级资源面板开合状态和资源标签状态；视窗交换和聊天区隐藏仅在当前应用运行期间有效。
- [x] 关闭资源面板时聊天区重新显示。
- [x] 资源面板在其他页面的可见条件仍由“跨页面联动”设置控制。
