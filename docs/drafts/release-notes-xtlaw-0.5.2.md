## 升级前请注意

- 本版本包含一条数据库迁移（新增 `user_questions` 表，数据库版本升到 43），首次启动时自动升级。升级后旧版本打不开新数据库，需要回退时请先备份数据目录。
- 设置里的“工具调用方式”改为关闭、混合调用、代码编排三种。原来开启 Codemode 的配置升级后显示为“混合调用”（原来的实际行为相当于“代码编排”，需要的话请手动改回）；配置文件本身不会被改写。
- 智能体打开网页现在默认在后台新开一个标签，不抢焦点，也不再接管你当前正在看的页面。
- DOCX、PPTX、XLSX 三个 Office 插件有新版本，请在插件市场更新：DOCX 0.1.16、PPTX 0.4.20、XLSX 0.3.19。

## 新增

- **异步提问**：智能体可以向你提问，同时继续做不依赖答案的工作，需要答案时再等你回答。问题在任务页底部以紧凑卡片显示，也可以展开到对话流里作答；支持单选、多选和自定义回答，回答后自动续接。
- **Codemode 三种模式**：关闭、混合调用、代码编排。
- **添加服务向导的模型步骤支持搜索**。
- **复制**：聊天选区右键菜单和 Markdown 预览右键菜单在“引用”上方新增“复制”。
- **Markdown 预览支持相对路径图片**，授权目录里的图片也能显示。
- **插件可读取任务统计和上下文用量**：插件在清单里声明 `permissions.data` 后，宿主以只读方式提供；安装审查里会单独列出。

## 改进

- **启动**：启动页显示真实进度；启动时已结束的运行不再重放事件，压缩改为服务就绪后在后台执行。
- **命令并发**：同一工作区内的 shell 命令可以和文件工具同时运行，改动重叠时结果标为部分完成；生成的文件先写入暂存目录再发布，写入失败会明确报错。
- **浏览器**：每次智能体运行使用自己的页面；运行被中止或超时时会停止加载并归还人工控制；浏览器会话上限由 4 提高到 16。
- **语音朗读**：控件和状态反馈更简洁。
- **问答面板**：层级、选中和悬停状态更清晰，多个问题时显示“问题 N / M”，历史记录折叠时显示回答摘要。
- **上下文用量**：跨轮次保留，压缩后刷新。
- **插件视图**：侧栏动画期间，插件视图和内置浏览器会跟着位置移动。

## 修复

- 压缩时模型返回空摘要，不再被当作压缩成功。
- 修复生图结果判定和重复提交。
- 修复补充消息延迟显示。
- 修复异常结果的消息排序。
- 修复恢复后的 Office 文档标签页在关闭后又自动重开。

## 插件更新

- **Office DOCX 0.1.16、Office PPTX 0.4.20**：收起功能区后，翻页箭头不再残留成两个空按钮。
- **Office XLSX 0.3.19**：拖动滚动条时，表格不再在拖动中途扩展列和行，滑块不再突然变短跳开。
