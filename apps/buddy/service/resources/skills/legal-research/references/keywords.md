# 关键词组织与调整

围绕检索命题形成查询，并根据检索结果持续调整。关键词不是一次性确定的清单，也不是把问题机械缩短。

## 一、从命题提取检索要素

先明确本轮要查找的材料或要回答的问题，再识别：

| 要素 | 需要识别什么 |
|---|---|
| 核心争点 | 真正需要查明的法律判断或争议 |
| 关键事实 | 可能改变规则适用或处理结果的事实特征 |
| 法律背景 | 法律关系、案由、相关规范或制度 |
| 表达线索 | 当事人的日常表述、交易用语、行业术语及专业名称 |

不要求每次凑齐全部要素，也不把所有要素一次输入。已经知道法名、条号、案号等明确标识时，优先按标识定位，不强行改成宽泛关键词。

检索命题应尽量准确、专业；实际查询可以使用法律术语，也可以使用日常或行业表达。

## 二、区分核心与辅助关键词

- **核心关键词**：体现本轮争点，缺少后容易偏离目标。先选能够表达争点的必要组合。
- **辅助关键词**：补充法律背景、具体事实或其他限定，用于提高结果贴合程度。
- 重要程度取决于当前命题，不固定认为案由最重要，也不固定认为某个事实词最重要。
- 核心关键词也可以在新材料出现后调整，不把最初选词永久锁定。
- 地域、法院、年份、程序等并非默认条件；确有任务要求或筛选需要时再限定。

## 三、发现和扩展关键词

### 1. 表达扩展：同一事项的不同说法

从同义或近义表达、词序变化、简称、全称、行业称谓和具体名称中寻找查询变体。

核对不同表达的含义是否相同。上位概念与下位概念、相近但不同的法律术语，不直接视为同义词。反义表达可以用于发现相反结果，但不属于同义替换。

### 2. 问题扩展：相关但不同的法律制度

结合请求、抗辩、构成要件及相关制度发现新的检索方向。

例如，无权处分与善意取得、无权代理与表见代理是关联问题，不是同义词。需要时分别形成子命题检索，不机械地合成一个同义词组，也不预设关联制度必然适用。

### 3. 从材料中发现表达

- **法条**：提取规范实际使用的术语和条件。
- **裁判文书**：关注事实认定、争点和裁判理由中的常见表述。
- **专业文章**：发现规则线索、概念及引用材料，再回原始材料核验。
- **背景与行业资料**：了解陌生事项，发现行业习惯用语或具体对象名称。

将新发现用于下一轮查询；重要发现可能需要调整命题，而不只是增加几个词。

## 四、把检索要素转成工具查询

| 检索方式 | 查询组织 |
|---|---|
| 网页、微信等搜索 | 使用简短且有辨识度的组合，必要时分别尝试专业表达与事实表达 |
| 数据库关键词检索 | 区分关键词与结构化筛选项；有对应字段时，将法院、日期等放入字段 |
| 语义检索 | 清楚描述争议问题和关键事实，不强行压缩成零散词语 |

- 不把同一条查询不加调整地复制到所有工具。
- 引号、排除词、OR、站点限定、同句、同段、间隔等语法，仅在当前工具明确支持时使用，按其参数和规则填写。
- 不默认搜索引擎语法适用于微信搜索或数据库接口。
- 提取重合字词只作为可选尝试；残缺词可能引入噪声，不作为固定步骤。
- 关键词策略不改变工具使用要求，不能以通用搜索代替固定保留的微信搜索。

## 五、根据结果调整，而不是重复搜索

| 结果表现 | 调整方向 |
|---|---|
| 结果多且不贴题 | 换更具体的表达、增加关键事实，或限定合适字段 |
| 结果少或没有结果 | 去掉非必要条件、换表达、拆开组合；检查工具语法是否正确 |
| 材料相关但未回答争点 | 从材料中发现新术语，检查概念、法律关系或案由是否判断有误 |
| 对领域缺乏基本认识 | 先读背景材料或初步案例，建立概念后再组织查询 |
| 结果集中于单一方向 | 针对相反结果、例外或限制条件补查，判断是否存在检索措辞偏向 |
| 工具报错或渠道受阻 | 作为工具或访问问题处理，不解释成关键词无效或材料不存在 |

一次调整应有明确目的，例如改变表达、补充某项事实或撤掉某项限制，不反复提交没有新依据的同一查询。

找不到时，也可以切换路径：先找案例倒查法条、先读文章发现线索，或按规范体系补查，而不是只在原查询上继续加词。

## 六、记录与结束

多轮检索时简记：本轮命题、实际查询、字段条件、渠道、结果及下一次调整原因。不为简单定位任务强制生成复杂日志。

- 发现新问题或命题有误：回到命题分析。
- 有明确材料缺口：定向补查。
- 已有核验材料足以回答：停止扩展关键词，不为凑轮次继续搜索。
- 调整表达和路径后仍无法补足，或渠道不可用：交代范围和缺口，不把“未检得”写成“不存在”。

关键词只帮助发现材料，不能替代正文读取、真实性核验或法律适用分析。检索用语避免包含无必要的个人身份信息及未公开商业信息。

## 七、查询组织示例

**命题**：交通事故中，鉴定确定的误工期超过定残日前一天，法院如何认定误工期？

以下只演示查询组织，不代表实际检索结果：

- 初始要素：误工期、定残、鉴定；交通事故作为背景要素。
- 核心组合：`误工期 定残`。
- 需要限缩时：增加`鉴定`，或按工具能力限定相关案由。
- 表达变体：分别尝试`定残日`、`定残之日`；查法条时注意其使用的`误工时间`等表述，不预设这些词在所有材料中完全等义。
- 读到相关裁判后：采用文书实际使用的期限认定表述继续查找；发现另一项争点时，另立子命题。
- 若字段、表达调整仍不贴题：从相关规范查关联案例，或从初步案例倒查规范，不机械增加全部事实条件。
