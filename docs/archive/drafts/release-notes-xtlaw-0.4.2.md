## 改进

- **下载镜像可在设置里开关**：设置的“代理”页新增“下载镜像”，打开后软件更新和市场插件包会优先走 GitHub 加速镜像，失败时回落到 GitHub 直连。下载内容都会校验大小与哈希，镜像无法替换文件。**默认不开启**（0.4.1 里更新包默认优先走镜像，现已改为需要手动打开）。
- Linux 版不再提供桌宠，设置里的“桌宠”页一并移除（Windows 版本来就没有）。

## 修复

- 修复工作中发送消息的控件错位。
- 修复待处理消息条的行高与间距。
- 修复无运行代码的插件包在市场里的卡片显示。
