# ArtPlayer

在文件页签中使用 ArtPlayer 5.4.0 播放音视频。视频采用左侧播放器、右侧「文字记录｜智能纪要」，默认约 60:40，可拖动分隔条或用方向键调整；窄页签自动改为上下布局。

- MP3、WAV、OGG、OGA、Opus、M4A、AAC、FLAC 使用顶部紧凑音频播放区：静态音频图标和文件名取代黑屏，文字记录与智能纪要位于下方。保留同一 ArtPlayer 播放实例及底栏，控制栏常显；没有动态音量分析或假动画，不新增权限。格式能否解码仍取决于当前环境。
- 底栏左侧原有的加载字幕操作保持不变，支持 SRT、VTT 或 ASS；右侧 CC 仍只开关画面字幕。同一个视频下次打开会沿用上次的字幕。
- 文字记录按阅读段落展示字幕，不虚构说话人。点击句子或时间戳跳转播放，播放时高亮当前句；手动滚动后停止跟随，文字稿底部居中出现悬浮的「回到当前播放位置」按钮，点击恢复跟随并隐藏。按钮不占据正文布局空间，按钮以外的悬浮区域不拦截文字选择和滚动。搜索支持命中计数、上一处和下一处，Enter / Shift+Enter 切换命中。
- 鼠标移到大段文字上时，时间戳旁显示引用图标，悬停提示「引用整段到 AI」；键盘聚焦段内内容也会显示，无悬停能力的设备常显。点击后打开与文字选区相同的聊天窗口样式菜单，以该段全部句子和起止时间作为冻结材料；只加入草稿、不发送，也不触发播放。超长段落提示改用选区引用，单句跳播保持不变。
- 在文字稿内拖选一句、部分文字或跨段内容后，不再自动弹出菜单；鼠标右键选区（或使用键盘菜单键 / Shift+F10）才显示与聊天窗口一致的两行「复制／引用」图标菜单。右键时拦截原生菜单，并在原右键位置显示同一菜单，不再叠出浏览器／Electron 的原生复制菜单。仅对文字稿正文取消原生菜单；搜索框和播放器保持原行为。整段图标与选区共用聊天窗口 `ChatSelectionQuoteMenu.vue` 的呈现：128px 窄菜单、6px 圆角、12px 文字、聊天窗口 small 菜单的 28px 行高和 14px Fluent 复制／引用图标、同款菜单阴影和主题悬停色；去掉 Office 菜单的分隔线和多余留白。多个目标的子菜单保留，引用、定位与原生菜单拦截逻辑不变。Fluent 图标的 MIT 声明随包附带。
- 引用采用宿主现有 `references.capture/commit/release`，打开菜单时冻结选区和可接收的聊天目标；一个目标直接加入，多个目标在「引用到聊天」子菜单选择，无目标时提示先打开聊天输入框。不再调用 `references.add` 弹出额外的目标选择框。关闭、滚动、失焦、更换字幕或主题变化时释放捕获；过期的异步结果不会换掉新菜单或跟随之后的聊天焦点。复制仅复制原文，引用只加入草稿，不自动发送、不调用模型、不上传整份字幕或媒体。
- 引用正文包含「文件路径、选中内容、字幕源媒体路径、时间范围」，其中路径只使用资源接口真正提供的 `relativePath`，并明确标成相对路径；拿不到路径时显示「路径不可用（文件名：…）」。不拼造绝对路径，不用资源 ID、临时媒体 URL 冒充路径。宿主仍绑定当前媒体来源以便重开视图，字幕资源标识和句子级时间、字符选区保存在不直接发送给模型的 locator 中。引用本身不扩大文件读取权限。
- 点击聊天引用的「定位来源」后，在当前或重新打开的播放器里加载引用所用的授权字幕、核对原文，再跳到对应句子的起始时间、展开文字记录并精确高亮选区，不自动播放。若字幕被修订，仅在原文唯一匹配时重新定位；原文缺失、存在歧义、句柄失效、版本不支持或取消时返回失败，不猜位置。定位旧引用不会覆盖为下次打开记忆的字幕选择。
- 选区引用上限 32768 个 UTF-16 字符，超出时禁用引用按钮；来源定位信息超过 16 KiB 时明确报错，不静默截断。新增 `references` 与 `clipboardWrite` 两项权限，需要更新插件授权；缺少所需接口的旧宿主会提示升级。本轮只修改本插件，没有修改宿主和 Office 系列。
- 「智能纪要」暂时仅为空占位，不调用 Agent、不附带 Skill，也不自动生成内容。
- 播放栏的「全屏播放」仅在当前文件页签内展开播放器、收起右侧面板；再次点击或按 Esc 恢复，保留分栏比例、右侧页签和文字内容。不是系统级全屏，不关闭画面 CC 字幕，不影响应用聊天栏。
- 不改 ArtPlayer 源码，不另做播放控制条。系统全屏、网页全屏和截图仍未开启。

加载字幕需要本地文件权限。安装时不会预选为默认播放器。在「设置 → 打开方式」里把对应后缀改为 ArtPlayer，关掉已打开的文件后再打开。

```sh
pnpm install
pnpm type-check
pnpm test
pnpm build
```

`dist/` 是可加载的 compiled 目录，ArtPlayer 已打进 `view.js`。单元测试覆盖音视频分类、文件关联、最小权限、字幕分段、搜索、选区边界、引用快照与定位校验、时间格式；不代替 Windows 宿主内的实机交互验收。
