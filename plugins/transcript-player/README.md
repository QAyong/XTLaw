# 文字稿

播放音视频，并手动加载 SRT、VTT 或 ASS。点一句就从那里播放，当前句跟着高亮。没有转写，也不会自动找同目录字幕。

第一版只做播放和跳转。搜索、引用到对话、跨页签恢复字幕、画面字幕开关和跳过空白都还没做。ASS 的说话人标签当前不会保留。

## 打开

安装时“文字稿”不会预选为默认播放器，内置预览保持不变。安装确认里可以主动勾选；之后也能在设置的“打开方式”，或文件菜单的“打开方式”里选择它。插件停用后，这些文件回到内置预览。

字幕用“加载字幕”选择。编码可选 UTF-8、GBK 或 UTF-16 LE。文件超过 8 MiB，或超过 20,000 句，会拒绝加载。

## 开发

依赖只在这个目录安装，不进入应用的 workspace。

```sh
pnpm install
pnpm test
pnpm type-check
pnpm build
```

`dist/` 是 `format: "compiled"` 的安装目录，已包含 ArtPlayer 5.4.0，不从 npm 或 CDN 加载。源码不改 ArtPlayer。
