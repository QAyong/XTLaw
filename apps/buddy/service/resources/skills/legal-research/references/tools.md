# 工具使用

| 能力 | 当前渠道或工具 | 使用关系 |
|---|---|---|
| 通用搜索 | 网页搜索，以及用户安装的其他搜索 Skill | 可替换、可扩展 |
| 专项搜索 | 微信搜索 | 固定保留，与通用搜索互补，不被其他搜索工具或 Skill 替代 |
| 专业数据库 | 北大法宝 MCP | 提供专业资料检索能力，后续可扩展其他数据库 |

- 开展搜索时，微信搜索作为固定专项渠道参与，不因使用其他搜索工具或搜索 Skill 而省略。
- 其他搜索能力可以替换或补充通用搜索，但不能默认视为已完成微信搜索；仅安装或启用其他搜索 Skill 也不改变这一要求。
- 当前微信搜索使用 `lexora_web_search`，明确指定 `provider: "sogou-weixin"`；普通网页搜索不等于微信搜索。
- 微信搜索受阻或不可用时，如实标记该渠道未完成，不以通用搜索结果冒充，也不绕过访问限制。遇到 `WEB_CHALLENGE` 等访问验证，立即停止该渠道，不重试、不绕过。
- 工具按能力选择，材料仍需单独读取和核验；不因来自某个渠道或数据库就直接采信。

## 来源层级

来源层级用于判断材料能承担什么作用，不替代对具体材料的读取与核验。

| 来源 | 一般用途 |
|---|---|
| 专业数据库（如北大法宝） | 精确查找、取得原文、核对标识和沿革；仍需核对所读版本 |
| 立法机关、法院、检察院、政府部门等官方平台及其官方账号 | 官方发布的规范、裁判和案例，可作实务引用；案号常不公开，须如实标注 |
| 律师或学者的文章 | 专业观点和线索，标明作者和日期后可引用，不当作法条或裁判原文 |
| 其他自媒体 | 只作检索方向，不作为引用依据 |

搜索结果只用来找线索，引用以读取到的正文为准。官方平台上的转载、解读、报道不等于规范正文或裁判原文，具体区分见 [材料筛选与核验](material-review.md)。

## 北大法宝 MCP

提供法规与法条、版本沿革、案例及其他文书、引用核验等专业检索能力。

- 北大法宝是内置连接器，默认关闭，用户在设置中填写 Token 后才能使用。未启用、未配置或额度不足时，如实说明该渠道未完成，改用网页和微信搜索，并按实际取得的材料收敛结论强度，不在回答中默认"已查数据库"。
- 根据当前任务发现所需工具，读取其实际描述后使用；已提供的工具定义直接使用，不重复发现，也不预先加载全部工具。
- 工具名称、参数、能力和返回范围，以当前 MCP 定义为准，不在本文重复维护逐项清单。
- 区分候选列表、原文和核验结果；检索命中不等于已读取正文，标识核对成功不等于适用性已确认。
- 正文加链不等于引用核验；材料仍须结合具体问题分析。
- 权限或额度出现问题时，再使用相应诊断工具。

### 使用注意

以下几点不在 MCP 工具定义里，使用前需要知道：

- **工具延迟加载**：工具未出现在当前可用列表时，用 `lexora_tool_search` 查找。一次只搜一个确切的英文工具名，并将 `limit` 设为 1；用中文描述搜不到，批量搜索会带回每个工具的完整类型声明，篇幅很长。
- **语义检索只作兜底**：语义检索单次费用较高、返回文本很多。先用法名、条号、案号、标题等明确标识和关键词检索，换表达调整后仍无合适结果时再用语义检索。
- **返回量大**：案例列表一次可能返回数十条记录，个别接口没有条数参数；返回内容超过一定大小时会被转为文件，只显示开头预览。预计要批量阅读时委派子代理（见 [子代理使用规则](subagents.md)），主代理只取索引和必要片段。
- **一次取全**：同一个检索不要因为想换个打印格式而重复调用。在同一次调用或脚本中把需要的字段（案号、法院、日期、相关理由摘录）一次取全，不整条打印。
- **不用于检索**：超链接补全、条文校正等编辑辅助类工具不作为检索手段。

### 调用节制

北大法宝按调用计费，额度有限。以下是软约束，目的是减少无谓调用，不能代替对任务本身的判断：

- **先精确后宽泛**：已知法名、条号、案号时，直接按标识查询；需要核验多个标识时，先查看工具说明是否支持一次传入多个，支持则合并调用，不逐个调用。
- **先线索后数据库**：不确定法名、条号或案由时，先用网页和微信搜索找线索，再用数据库取原文，不用数据库做试探性检索。
- **按任务规模控制**：简单定位任务的数据库调用通常不超过个位数。预计明显超出时，先向用户说明原因和大致规模，再继续。
- **核验分轻重**：只对支撑结论或影响结论的材料调用数据库核验，不对每份线索逐一调用。
- **避免重复**：同一内容已取得并保存在日志或工作区时，直接读取，不再次调用。委派子代理时，在任务中写明已查过的内容和可读取位置。
- **关注余额**：开始预计耗用较大的任务前，可查询一次余额（账户类工具，不计费）。额度中途不足或调用被拒时，按"渠道未完成"处理：如实说明，改用其他渠道，并相应收敛结论强度。
