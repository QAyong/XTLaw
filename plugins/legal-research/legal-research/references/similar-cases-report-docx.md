# 类案检索报告 DOCX 版式

## 何时使用

- **只有用户明确要求 DOCX（Word 文档）时才用本文件。** 用户没提格式、只说“出一份报告”，按 [类案检索报告模板](similar-cases-report-template.md) 交付，不主动改 DOCX，交付后也不追问要不要 DOCX。
- 内容、章节、案例分组、核验要求和中立、边界规则，全部以类案检索报告模板为准，DOCX 与 Markdown 版内容一致；本文件只规定版式和落地办法。不为版式增删内容。
- 字体和版式借用公文格式（GB/T 9704 的通行做法），但报告不是发文：不加红头、发文字号、签发人、印章、版记、抄送、主题词等公文要素。

## 版式

| 项目 | 要求 |
|---|---|
| 纸张与页边距 | A4；上 37 mm、下 35 mm、左 28 mm、右 26 mm（版心 156 × 225 mm） |
| 报告标题 | “类案检索报告”，方正小标宋简体、二号，居中；标题与正文之间空一行 |
| 一级标题 | 黑体、三号，序号“一、”，左起顶格 |
| 二级标题 | 楷体_GB2312、三号，序号“（一）”，首行缩进 2 字符 |
| 三级标题 | 仿宋_GB2312、三号、加粗，序号“1.”，首行缩进 2 字符 |
| 四级标题 | 仿宋_GB2312、三号，序号“（1）”，首行缩进 2 字符 |
| 正文 | 仿宋_GB2312、三号，首行缩进 2 字符，两端对齐，行距固定值 28 磅，段前段后 0 |
| 数字和字母 | Times New Roman（与仿宋搭配的通行做法），含案号、条号、日期中的数字 |
| 原文摘引 | 楷体_GB2312、三号，左右各缩进 2 字符，首行不缩进，行距同正文 |
| 表格 | 表宽同版心，0.5 磅细线边框；表头黑体、四号、居中；表内文字仿宋_GB2312、四号，行距固定值 22 磅，单元格上下留 1 磅；表格宽度不超出版心 |
| 页码 | 宋体、四号，格式“— 1 —”，位于页脚；奇数页靠右、偶数页靠左，各空一个汉字。工具做不到奇偶页不同时居中 |

表格和页码的规格公文国标未细分，是本技能的约定。

**字体写法：** 字体和字号写进文档样式，不逐段手调。中文字体写东亚字体属性，数字和字母字体写 Times New Roman。机器上没有这些字体也照写原字体名，不替换成别的字体。

## 结构对应

标题和章节沿用类案检索报告模板，序号改为公文序号：

| 模板 | DOCX |
|---|---|
| 1. 检索目的 … 8. 检索用时 | 一、检索目的 … 八、检索用时（没有记录则整节不写） |
| 4-1、4-2、5-1、5-2、5-3、6-1、6-2 | （一）、（二）、（三） |
| 4-2-1 规范类别 | 1. 规范类别 |
| 案例①：标题 | 三级标题样式，序号沿用“案例①”，不再另加“1.”，避免与分析中引用的案例编号出现两套 |
| 6-2 下的各项（样本情况、支持的理由与条件等） | （1）（2）……四级序号，每项以项目名和冒号开头 |
| 1-1、1-2 检索问题 | “一、检索目的”下用“（一）”“（二）”分段写 |

## 内容的写法

- **案例信息**：用两列表格，左列项目名（黑体、四号）约占 30 mm，右列填写内容；项目沿用模板（原文链接、内容来源、案号、审理法院、裁判日期、文书类型及审理程序、参照级别、相关事实、裁判结果）。无补充内容的项整行删除，与模板一致。
- **裁判要旨／相关裁判理由**：作为三级标题下的加粗引导行，下面用“原文摘引”样式。归纳另起一段，开头标注“归纳”。
- **链接**：数据库返回的原文链接必须附上。案例标题和“原文链接”一行都做成可点击的超链接，“原文链接”一行同时显示完整网址，打印后仍可核对。链接用文档默认超链接样式，不改字体。
- **规范条文**：条文原文用“原文摘引”样式，“效力与适用时间”“来源”两行用正文样式。
- **比较表、分组汇总**：按需用表格，格式同上。
- **占位符**：模板里所有【】占位符和“（可选）”“无则删除”提示都不保留。

## 生成与自检

- 内容按模板写完并核验后再生成 DOCX。用当前可用的 DOCX 能力生成（已安装的 Office 文档技能、命令行工具或脚本库均可）。没有可用能力时如实说明，改交 Markdown 版，不声称已生成。
- 生成后重新读取文件，核对：没有残留的【】；序号连续；案例编号与分析中的引用一致；字体、页边距、页码按上表设置；链接可点击；表格没有超出版心。能渲染预览时看一遍分页，避免案例信息表被拆得难以阅读。核对不到的项如实说明，不写“已核对”。
- 保存到用户指定的位置，没有指定则放在任务工作区，文件名 `类案检索报告-简短命题-YYYYMMDD.docx`；交付时告知路径。
- 交付时提醒一句：方正小标宋简体、仿宋_GB2312 等字体不是每台电脑都有，未安装的电脑会用替代字体显示，字体名仍保留在文档里。
