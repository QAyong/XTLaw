# Spec-053：文件管理器图片标注与对话引用

**日期：** 2026-11-22

**状态：** 第一版范围已确认，开发中

**相关规格** [Spec-013 工作台选区引用与多分屏目标](feature-013-workbench-selection-reference.md)

## 1. 背景与目标

在文件管理器查看截图、设计稿或流程图时，用户可以直接框出要讨论的位置。例如圈出两个按钮，引用到对话，再写「① 左移一点，② 的文案改短」。聊天历史可以回看当时引用的带编号图片。

本稿的第一版范围是**静态图片预览、矩形框选、自动编号、撤销、引用到指定对话**。引用的内容是一份带编号的整图快照，保留画面上下文。原始图片文件继续由文件管理器正常读取。

## 2. 第一版交互

1. 在文件管理器打开一张可正常预览的静态 PNG、JPEG 或 WebP。预览工具栏提供「标注」。进入后显示「撤销」「引用到对话」和「退出标注」。
2. 在图片上拖出矩形。每次有效框选按顺序显示编号 ①、②、③。起点取图片内的位置，终点拖出画面时收在图片边界。单击和空框略过。
3. 「撤销」移除最后一个框，后续添加的框沿用空出来的序号。绘制中按 `Esc` 取消当前拖动，已有框仍可使用。没有有效区域时，「引用到对话」不可用。
4. 点击「引用到对话」时，沿用 Spec-013 的规则。单窗且有唯一明确目标时直接加入该草稿。分屏时显示目标名称，有多个候选且归属不明确时由用户选择。取消选择后回到图片，已画的框可继续使用。
5. 将原图、框和编号合成一张 PNG。导入成功后，目标草稿出现可预览、可移除的图片附件。用户可以继续在聊天输入框写说明，并沿用原有发送方式。缩略图和聊天历史都使用这份快照。
6. 标注保存在当前预览的临时状态里。成功引用后可以继续查看和撤销。主动退出标注、切换文件或重新加载图片后，新一轮从空白标注开始。已经加入草稿的快照独立保存。

第一版从文件管理器入口提供功能，覆盖上述三种静态格式。箭头、自由笔、多色工具、动图、SVG、聊天图片上的标注入口，以及把标注存成独立工作区文件，留待后续需求确定。

## 4. 新增实现与异常处理

### 4.1 坐标和快照

- 以图片实际显示区域换算原图像素坐标。矩形保存左上角和宽高，以同一套坐标重绘预览与导出层。预览留白、面板尺寸变化和高分屏缩放应得到同一块原图区域。
- 通过 `Canvas 2D`（浏览器二维绘图接口）合成 PNG，保证导出编号和预览编号一致。导出使用用户正在查看的已解码画面。原图文件的字节保持不变。
- 复用现有附件限制约束导出。实现时验证现有文件预览地址在桌面端的 Canvas 导出能力和大图内存占用。导出失败或附件超限时提示原因，并保留当前标注供重试。

### 4.2 草稿与切换

- 引用操作开始时记录当前图片预览和选定的草稿。异步导入完成时再次核对来源、目标和草稿。期间切换图片、关闭视图或更换目标草稿，操作在原目标失效后结束，不落到后来选中的草稿。
- 导出和导入期间限制重复提交。附件成功加入草稿并持久化后才显示引用成功。目标不可用、导入失败或保存失败时沿用现有反馈机制，仍打开的标注可供重试。
- 引用成功后的附件独立于原文件。磁盘图片后续被修改、移动或删除时，已保存的草稿和历史仍能打开当时的标注快照。

## 5. 验收条件

- [ ] 在文件管理器打开静态 PNG、JPEG、WebP，进入标注后可框选两个区域，画面分别显示 ①、②。普通预览中仍可按原有方式查看图片。
- [ ] 撤销 ② 后下一框使用 ②。单击和空框不生成编号。拖到图片外的部分收在图片边界。
- [ ] 选择同一原图区域后，改变窗口或资源面板宽度，框和编号仍贴住同一位置。导出图与预览里的区域一致，并保留整图上下文。
- [ ] 单窗时能将 PNG 加入明确的目标草稿。存在多个候选时，用户可以确认引用到哪一窗，其他草稿保持原状。取消选择时，标注仍可编辑。
- [ ] 快速连续点击只完成一次导入。导入期间关闭来源或切换目标草稿，附件不会落到新草稿。导出或导入失败后可以重试。
- [ ] 可以从草稿预览或移除附件。发送一轮图片加文字时，支持图片输入的模型能看到编号并据此区分两处。应用重启后，历史仍可打开带编号的快照。
- [ ] 对原图做前后字节比较，标注和引用过程没有写入原图。引用后修改或移走原文件，已保存的快照仍可打开。

开发时用定向测试覆盖坐标换算、拖动越界和目标失效，再在 Windows 开发版验证文件管理器预览、分屏目标和发送到模型的图片请求。

## 6. 待确认事项

- **是否需要从聊天回跳到原图区域。** 草案先采用图片快照。如果希望点聊天里的标注回到文件管理器并高亮对应区域，需要一并保存来源文件身份、所见版本和区域坐标。现有的 [`createQuoteSourceOpener`](../../apps/buddy/src/app/workbench/openQuoteSourceFile.ts) 提供打开来源文件的入口，区域定位和原图版本变化时的反馈需要另行设计。
