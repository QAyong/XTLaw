## 升级前请注意

- 本版本新增 1 个数据库迁移（变更记录增加“覆盖原因”和“捕获方式”），首次启动新版本时会自动升级本地数据库，升级后不能回退到旧版本。建议升级前先在设置里创建一份备份。
- **Office 插件不再随应用预装**：DOCX、PPTX、XLSX 三个插件改为在插件市场下载。已经安装的插件会保留，数据不受影响。
- **自动化的审批策略与免确认白名单已移除**：0.3.0 里按自动化单独设置的这两项，被统一的全局网络权限规则取代；已有自动化里保存的相关设置会被忽略。

## 新增

- **网络权限与空间目录授权**：完善了网络权限规则，一个空间可以授权多个目录，文件夹产出会按空间的全部目录解析；新增功能引导。
- **文件编辑器自动保存**：文件管理器里编辑文件时可以自动保存。
- **复制会话为 Markdown**：可以把整段对话复制成 Markdown。
- **图片和流程图预览支持滚轮缩放**。
- **音频、视频和图片预览改为流式读取**：长音视频可以直接拖动进度条，大图不再整张读入内存；技能里的图片也走同一条通道。
- **没选本地文件夹的空间**：其默认文件夹可以在文件管理器里浏览，对话里的相对路径文件链接也会按默认文件夹打开。
- **插件**：插件可以配置多个 Shell；扩展包里用根路径引用的字体和图片现在能正常加载。
- **设置与任务**：记住上次访问的设置页；任务列表优先显示所在空间内的任务；无空间任务移入空间改为对话框确认，并加强了校验。

## 改进

- 产出卡片缩小到 192 像素。
- 命令执行不再扫描整个工作区，启动更快。
- Windows 沙盒退出更快。
- 依赖升级：Electron 44.9.3、electron-vite 6 等。
- 持续集成里新增 Windows 受限令牌下的 ACL 验证，并隔离了 Windows 验收的用户环境。

## 修复

- 修复等待中的消息队列与“即时补充”的问题。
- 修复使用 ChatGPT 登录时误开放生图工具的问题。
- 修复只携带拖入本地文件、没有文字的用户消息不显示的问题。
- 修复 Markdown 列表编号被截断的问题。
- 修复 Codemode 在并发已满时直接失败的问题。
- 修复沙盒工具链环境变量没有正确继承的问题。
- 修复文件被移动或删除时与其他预览失败混在一起的提示。
- 修复 Windows 沙盒在 PATH 中遇到无权读取的目录时的处理。
- 修复插件清单兼容性问题和 Office 插件标签页的外部打开。
- 修复原生命令在 Windows 上因管道关闭而丢失真实退出错误的问题。
