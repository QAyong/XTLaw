# 法律检索员（子代理）

一个只读的 NPC 子代理。安装后自动加入“晓晓”的可委派列表，用于按命题检索、读取并核验中国大陆法条与案例，回传简明发现和可追溯依据。委派规则与应用内 `legal-research` 技能的「子代理使用规则」一致。

- 工具范围：读文件（read、find、grep、ls）、网页搜索与抓取（含微信搜索），以及北大法宝 MCP 的全部工具。没有写文件和命令行工具，所以不能修改文件。
- 北大法宝需要在设置中填写 Token 并启用；未启用时它的工具不可用，法律检索员仍可用网页和微信搜索检索，并会如实说明数据库渠道未完成。
- 卸载时会一并从“晓晓”的可委派列表移除；你改过的定义会保留。
