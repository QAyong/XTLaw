# 17. Office DOCX 插件

PI-Desktop 内置 `pi.office` 插件，用于在工作面板中打开、预览和编辑已有的 `.docx` 文件。编辑器是从插件 `UPSTREAM.md` 中锁定的 GenOffice 发行版里提取出来的浏览器渲染器。

宿主负责文件引用补全和工作面板标签。插件负责 DOCX 解析、渲染、编辑、序列化以及文件字节。从项目文件管理器或聊天中打开的 DOCX 文件，在视图可用时会路由到 `pi.office`；其他文件类型保持原有路由。

文件生命周期是有界且乐观的：读取会返回指纹；除非用户明确确认覆盖，否则保存会拒绝意外的 mtime/size/hash 变化；写入使用同目录临时文件，执行 fsync 后再替换。恢复副本保存在插件数据目录下。非 DOCX 文件、类凭据路径、工作区之外的路径、目录以及超过 64 MiB 的文件都会被拒绝。

渲染器没有 Node 或 Electron 访问权限，视图的 CSP 禁止网络连接。本次迁移有意排除选区转聊天、批注、Composer 标注和段落锚点协议，也不包含新建文档、另存为、原生 Microsoft Office/COM、GenOffice AI、账号、远程服务或 MCP 集成。

编辑器缩放范围为 25%–200%。打开文档时保持编辑器正常的缩放行为；当需要显式适配模式时，用户可以使用页宽和整页命令。重建或重新加载插件视图后，会在视图重建完成之后再重新挂载原生工作面板表面，以使周围的工作面板控件保持可交互。
