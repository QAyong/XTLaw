# 法条检索

先法后案：检索结果里可以没有案例，不能没有法条。实务检索和类案检索都从这里取法条，一般检索核对法条时也用这里的工具。

## 法的范围

**纵向：效力位阶。** 法宝 `get_law_list` 的 `effectiveness` 可按下列位阶筛选：法律、行政法规、监察法规、司法解释、部门规章、军事法规规章、党内法规制度、行业规定、团体规定、地方性法规、自治条例和单行条例、地方政府规章、地方规范性文件、地方司法文件、地方工作文件、行政许可批复。

**横向：法律部门。** 宪法及其相关法、民商法、行政法、经济法、社会法、刑法、程序法。

**技术标准：** 国家标准、地方标准、行业标准。涉及时用网页搜索找官方来源，法宝的法规工具不一定覆盖。

## 三种检索方式

### 直接检索

事项明确、法律适用明确时用。

| 情形 | 工具 |
|---|---|
| 已知法名和条号 | `get_law_item_content`（`title`、`tiao_num`，如 2 为第二条，2.1 为第二条之一）；`get_article` 也可（`title`、`number` 写"第四十八条"） |
| 法名不全或不确定 | `get_law_list`，用 `title` 或 `fulltext` 找候选，看效力位阶和时效，再读原文 |
| 只知道含义，不知道法名条号 | 不用语义检索。按下面的"间接检索"，先用搜狗微信和网页找线索，再回法宝核对 |
| 线索和关键词都找不到 | 兜底才用 `search_article`（语义），只用一次，`size` 不超过 5，可按 `lib`、`timeliness` 筛选，并在回复里写明用了语义检索 |

### 体系检索

比直接检索慢，但答案全面。下列情况必须做：陌生领域；结论需要全面；条文里出现"法律规定的其他情形""依照有关规定"这类兜底表述。

1. **纵向：** 确定核心法律后，按位阶逐层查：法律、行政法规、司法解释、部门规章、地方性法规、地方政府规章。用 `get_law_list` 的 `effectiveness` 加 `fulltext` 关键词；或用 `list_related_statutes` 直接列出这部法的上位法、下位法、司法解释、被修改和被废止的关系（只含图谱已收录的，不是全库穷尽）。
2. **横向：** 想事项还涉及哪些法律部门。例如建设工程施工合同纠纷，除民法外，还可能涉及行政法规和行政法。
3. **地方：** 需要地方性规定时，用 `get_law_list`，`effectiveness` 选地方性法规、地方政府规章、地方规范性文件，`title` 或 `fulltext` 加上法院所在地或行为地的名称。
4. 把各层查到的整理成一份清单，标明位阶和时效，再按与命题的关联度排序。

### 间接检索

陌生领域、直接和体系检索都无从下手时用：先通过文章、案例找到法条线索，再回法宝核对。

1. 用 `lexora_web_search`（网页，或 `provider` 为 `sogou-weixin` 的搜狗微信）搜相关文章，找文中引用的法律法规。搜狗微信常是最快的入口，公众号文章常直接列出法律依据。
2. 或从案例"本院认为"部分引用的法条入手。
3. 把线索里的法名和条号拿到法宝逐一读原文核对。文章里的法条只是线索，不能直接引用。

## 核对与沿革

- 读原文，核对标题和条号。`get_law_item_content` 的 `title` 要用 `get_law_list` 返回的完整标题，含"(2020修正)"这类后缀；标题不精确会返回空，不要因此逐条试条号。
- 看时效：已废止、已被修改、尚未施行的，不能当作现行引用。
- **沿革：** 先 `list_law_versions` 看这部法有几个版本和各版施行区间；再 `get_article_history` 查某一条的历次文本，`asOf` 传事实发生的时点，看当时适用哪一版；需要对比两版差异时用 `diff_article_versions`。
  - `articleNumber` 按现行条号解释；旧版条号见各版的 `articleLabel`，不要把新旧条号合成一条时间线。
  - 图谱未覆盖时只返回法规库定位，不代表完整沿革，写进"注意"。
- 上下位法是否冲突、新法是否废止旧法，用 `list_related_statutes` 查。
- 司法解释、会议纪要、指导意见，标明名称、发布日期和施行日期，写明是司法解释还是其他文件。
